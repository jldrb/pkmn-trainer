# Champions Stat Trainer, phone version

Upload every file in this folder (not the folder itself) to a GitHub repository,
then turn on GitHub Pages for it (Settings, Pages, deploy from the main branch, root folder).

Open the Pages link on your phone:
- iPhone: open it in Safari, tap Share, then Add to Home Screen.
- Android: open it in Chrome, tap the menu, then Install app (or Add to Home screen).

After the first visit the app works offline. Pictures you have already seen stay cached.
Progress is stored per device: use Save, Download save file / Load save file to move it.
To update the app later, replace index.html in the repository with the new one.
